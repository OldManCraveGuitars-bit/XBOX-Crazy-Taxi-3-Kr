# V1.0 검수 범위

게임 패치 내용은 최종 검수 빌드 r18을 기준으로 배포합니다. V1.0은 배포 버전명이며 가사 전곡 완전 수록을 의미하지 않습니다.

## 가사

오디오 파일 17개 중 12개에 총 260개 자막 구간이 있습니다. 영어 곡명과 `♪` 접두사를 사용하고 공백은 반각으로 처리했습니다. 기존 번역과 여러 음성 인식 결과를 대조했으나 직접 청취에 의한 전 구간 확정은 완료하지 못했습니다. 자막이 없는 시간은 연주 또는 미확정 보컬일 수 있으므로, 자막 사이 빈 구간이 전부 연주라고 단정하지 않습니다.

다음 오디오는 가사 자막을 수록하지 않았습니다.

| 게임 내 파일 | 길이 | 상태 |
| --- | ---: | --- |
| `01_special_delivery.adx` | 약 9초 | 짧은 루프, 가사 미확정 |
| `02_hear_it.adx` | 약 11초 | 짧은 루프, 가사 미확정 |
| `07_ignition.adx` | 약 17초 | 짧은 루프, 가사 미확정 |
| `12_who_the_hell_cares.adx` | 약 10초 | 짧은 루프, 가사 미확정 |
| `16_crash_US.adx` | 약 130초 | 가사 미확정 |

위 파일명은 일본판 안에 들어 있는 오디오 이름입니다. `US`라는 파일명이 다른 지역판 패치 지원을 뜻하지 않습니다. 나머지 12개 파일도 모든 보컬 구간의 자막 수록을 보증하지 않습니다.

## 게임·번역 검수

최종 번역·텍스처 검토 목록은 938행입니다. 저장·불러오기에서 공유되는 조사, 저장 화면의 게임·리플레이 주어가 잘리는 문제와 가사의 불확실한 관계 표현을 최종 단계에서 정리했습니다. 이름·목적지·가사 외곽선, UI 중앙 정렬, 저장 안내문 범위도 재검토했습니다.

- x86 동작 검증: 53개 그룹
- UI 배치 실행: 1,446개
- 게임 이미지 내부 파일 검증: 401개
- 수정된 파일: XBE 1개 + 텍스처 아카이브 9개
- 동일하게 유지된 파일: 391개, 음악 아카이브 포함
- xdelta 역적용 결과: 최종 한글 ISO의 크기·SHA-256과 일치

위 수치는 자동화·정적 검수의 범위를 나타냅니다. 메뉴의 모든 조합이나 플레이 전체를 실제 화면으로 검증했다는 뜻은 아닙니다.

## 실기 관련 정적 검토

실기 테스트는 수행하지 않았습니다. 실행 파일을 원본과 비교해 허용한 한글 처리·자막·배치 변경 외의 변조가 있는지 확인했습니다.

- 원본 섹션의 배치와 시작점·가져오기 정보·TLS·스택·힙 설정을 보존했습니다.
- 한글·자막 처리를 위한 `.KRSUB` 섹션 47,712바이트를 추가했습니다.
- 고해상도 텍스처의 전체 DXT 데이터 증가는 약 2.68 MiB입니다. 이는 모든 텍스처의 합계이며 실기 최대 동시 메모리 사용량을 측정한 값은 아닙니다.
- 한글 폰트 텍스처를 2 MiB로 줄이고, 화면 전환 때 사용할 수 없는 폰트·음악 자원을 건너뛰도록 처리했습니다.
- 원본 ASCII 폰트 페이지와 문제 제보된 메뉴 프레임의 바이트를 보존했습니다.
- 최종 r18에서는 r17 대비 새로운 후크·가져오기·실행 API를 추가하지 않았으며 실행 명령열과 할당 크기도 유지했습니다. r18 변경은 번역 문구와 관련 글자 리소스에 한정했습니다.

수정된 XBE는 이를 실행할 수 있는 Xbox 환경이 필요합니다. 정적 검수는 실기 모든 장면의 안정성을 인증하지 않습니다.

## EXE 패처 검증

현재 배포 패처는 1.0.1 C#/.NET 버전입니다. 원본 파일을 읽기 전용으로 열고 작업 중 쓰기·삭제 공유를 허용하지 않습니다. 임시 출력에서 디코딩과 SHA-256 검증을 완료한 뒤 새 ISO 이름으로 저장합니다. 원본이나 기존 출력 파일은 덮어쓰지 않습니다. 취소·오류 시 해당 작업이 만든 임시 파일만 정리합니다.

합성 데이터 테스트 15건과 폼 배치 검사를 통과했습니다. 복사·추가·0 채움 연산, 잘못된 원본, 손상 데이터, 범위 초과, 잘린 명령, 결과 해시 오류, 취소, 원본 쓰기 잠금과 출력 경합을 검사했습니다. 배포 EXE의 통합 검증 8건에는 실제 지원 원본 적용과 원본·출력·보고서 보호 검사를 포함합니다. 생성된 ISO는 V1.0과 동일한 SHA-256입니다.

현재 검증 결과는 [patcher-verification-1.0.1.json](patcher-verification-1.0.1.json), 백신 검사 결과는 [antivirus-check-1.0.1.json](antivirus-check-1.0.1.json)에 기록했습니다. [release-verification.json](release-verification.json)은 회수한 초기 PyInstaller 패처의 과거 검사 기록입니다.
