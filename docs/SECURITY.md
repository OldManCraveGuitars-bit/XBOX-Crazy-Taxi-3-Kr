# 패처 1.0.1 검사와 수정 내역

실행할 때 바이러스 경고가 나온다는 제보를 받고 초기 EXE 배포를 회수했습니다. 정확한 보안 제품·탐지명이 확인되지 않아 제보를 재현하지 못했으며, 오탐이나 SmartScreen 경고라고 단정하지 않습니다.

초기 EXE와 새 EXE를 2026-11-07 Microsoft Defender의 정의 `1.463.169.0`, 엔진 `1.1.26100.4`로 검사했습니다. 두 파일 모두 해당 로컬 사용자 지정 검사에서 위협 탐지 없이 검사 완료 이벤트 1001이 기록됐습니다. 백신과 실시간 보호를 켠 상태에서 검사했으며, [원본 검사 기록을 요약한 JSON](antivirus-check-1.0.1.json)을 공개합니다. 다른 보안 제품의 판단이나 제보한 컴퓨터에서 내려받은 파일까지 확인한 결과는 아닙니다.

## 배포 구조 변경

초기 버전은 PyInstaller onefile로 Python 런타임과 xdelta 실행 파일을 포함했습니다. [onefile은 실행 시 임시 디렉터리에 지원 파일을 추출하는 구조](https://www.pyinstaller.org/en/stable/usage.html)이며, 기존 빌드 명령과 소스에서도 이 동작을 확인했습니다. 이 구조가 이번 경고의 원인이라고 확정한 것은 아닙니다.

새 패처는 일반 C#/.NET EXE로 다시 작성했습니다.

- Python·PyInstaller와 외부 xdelta EXE를 포함하지 않습니다.
- 내장 리소스는 `CT3.patch` 하나이며, 오프셋·길이·변경 데이터만 담은 gzip 데이터입니다.
- 디코더는 원본 복사, 변경 데이터 쓰기, 0 채움의 세 연산만 처리합니다.
- 외부 프로그램 실행, 실행 파일·DLL 추출, 네트워크 접근, 레지스트리·시작 프로그램 등록 기능이 없습니다.
- 매니페스트의 실행 권한은 `asInvoker`입니다. 관리자 권한을 요구하지 않습니다.
- 원본은 읽기 전용으로 잠그고, 기존 출력·보고서는 덮어쓰지 않습니다. 내부 데이터·원본·결과의 SHA-256을 확인합니다.

새 EXE는 **1,228,800바이트**이며 SHA-256은 다음과 같습니다.

```text
bd7a9329574e9b131a5fa80f488c6a3a667ec0e8649f936e6e2994540edd1d22
```

[소스·실제 EXE 검증 기록](patcher-verification-1.0.1.json)에 15개 데이터 테스트, 폼 배치 검사, 8개 통합 검증을 기록했습니다. 실제 일본판 원본에 새 EXE를 적용해 기존 V1.0과 동일한 한글 ISO 해시가 나오는지 확인했습니다. 게임 번역·텍스처·XBE 내용은 바뀌지 않았습니다.

## 서명·평판 경고의 한계

새 EXE도 상용 코드 서명 인증서로 서명하지 않았습니다. Microsoft는 [SmartScreen이 다운로드 파일의 평판을 확인하며 미서명 또는 평판이 낮은 앱에 경고할 수 있다](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)고 설명합니다. 이러한 발행자·평판 경고와 특정 악성코드 탐지명은 구분해야 합니다. 이번 변경과 로컬 백신 검사만으로 모든 환경에서 경고가 사라진다고 보장하지 않습니다.
